TimeSense — daily open experience

Every style,
rolling past once.

Shown on the first open of each local calendar day. All the timer-style icons move past horizontally like a conveyor belt — one full pass through the set, then it auto-advances to Home. The point is to say "this app has range" in five seconds, without a single word of copy doing the explaining. The belt closes on Cat Loaf — the app icon.

How the belt behaves

One continuous horizontal scroll, right to left, at a constant speed — no easing per icon, no pause-and-snap. It should feel like a single smooth pass, not a slideshow.

  • One loop only. The belt travels the width of all 8 icons exactly once, then stops and auto-advances to Sign Up — it does not loop indefinitely. A new user shouldn't feel like they're waiting for something to end.
  • Caption follows the centered icon. Whichever icon is nearest the horizontal center updates the name + one-line description beneath — this is the only text on screen, so it should always match what's actually centered.
  • Skip is always available, top-right, from the very first frame — this screen should never feel like it's blocking someone who already knows they want the app.
  • Total duration: ~4–5 seconds for the full pass — fast enough to not feel like a delay, slow enough that each icon is legible for a beat as it crosses center.
TriggerFirst open each local calendar day — AsyncStorage timesense.showcase.last_shown_date (YYYY-MM-DD). Same day reopen skips it.
Auto-advanceFires when the belt finishes its single pass — goes to Home (not Sign Up every day). Skip is always available top-right.
OrderRadial → Slices → Plant → Moon → Sky → Garden → Monk → Cat Loaf — ending on the app icon (Cat Loaf): cream loaf, crust-dark ear inners, basil eyes on --crust.
Reduced motionIf the OS reduced-motion setting is on, replace the moving belt with a static row of all 8 icons (no scroll animation) plus the same captions shown as a simple stacked list.
Storyboard — key moments in the pass
Why Cat Loaf closes the sequence: it is the app's chosen icon (Section 8). Ending the daily belt on it creates a small recognition beat — same cream loaf, crust-dark ear shading, and basil eyes on a crust background as the home-screen mark. Shown once per local calendar day, then Home.
